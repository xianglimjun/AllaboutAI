01 / The idea

The model is the mind.
The harness is the agency.

A raw LLM can predict the next token. A harness gives it a job, a place to work, and a way to learn what happened after it acted.

Useful mental model
The harness is the control plane. It decides what the model can see, what it can do, and when its work is good enough.

02 / MCP

Model Context Protocol
is the tool contract.

MCP standardizes how a harness discovers tools, requests actions, and receives structured results. It makes tools portable across models and clients, so you can swap infrastructure without rewriting the agent loop.

Read the full MCP guide →
01

Discovery

The harness can enumerate available capabilities and their schemas before planning.

02

Invocation

Tool calls are explicit and validated, reducing brittle prompt-level parsing.

03

Interoperability

One protocol supports many servers, enabling consistent cross-environment tooling.

03 / Skills

Skills let a harness
delegate with intent.

Skills package domain playbooks, tools, and policies into reusable capabilities. They help the harness route tasks to the right workflow instead of forcing one generic loop to handle every job.

Read the full Skills guide →
01

Task fit

Each skill narrows scope and context, increasing precision for specific work types.

02

Safety

Skills can enforce scoped permissions and checks before high-impact actions.

03

Throughput

Specialization reduces reasoning overhead and speeds multi-step task completion.

05 / Blueprint

Build the
smallest loop.

Start with one job and one tool. Add complexity only when the feedback says you need it.

See the principles ↓
job: ship a safe change
model: reasoner
tools:
  - read_files
  - run_tests
  - write_patch
loop:
  observe → decide → act → verify
stop_when: tests_pass && diff_is_small
The good harness checklist
01

Bounded

Clear permissions, budgets, and stop conditions.

02

Observable

Every action leaves a trail you can inspect.

03

Correctable

Humans can pause, redirect, and undo the work.

04

Evaluated

Success is measured against the actual job.
